# Regex Data Extractor

A simple Python project that uses Regular Expressions to extract structured data from a text file.

## Features

- Extract email addresses
- Extract phone numbers
- Extract URLs
- Extract dates
- Remove duplicate results
- Count the number of unique results

## Technologies Used

- Python
- Regular Expressions (`re`)
- File Handling
- Sets

## Extracted Data Types

### Emails
Example:
`rana.mahmoud@example.com`

### Phone Numbers
Example:
`0791234567`

### URLs
Example:
`https://www.example.com`

### Dates
Example:
`12/05/2026`

## Skills Practiced

- Regular Expressions
- Pattern Matching
- Text Processing
- File Handling
- Lists and Sets
